- [x] **T5. Predicted share on v1. DONE 2026-10-05 — architectural gap exposed.**
  `shelf-eval --predict` wired (T3 DINOv2 matcher + T4 CLIP can/glass), 176
  tests passing (168 + 8 new in `test_predict.py`). Real run on hemin GPU:
  `runs/eval/20261005-192020/` (synced locally).
  **Result: share error is huge and the direction is expected.**
  - canned_drinks: GT share 69.0%, predicted 31.4% (-37.6 pp)
  - glass_drinks: GT share 29.8%, predicted 2.9% (-26.9 pp)
  **Root cause (architectural, not a code bug):** the threshold 0.0625 was
  tuned on 245 *named* gold crops (should-match / should-not-match ground
  truth). The detector fires 2,457 boxes — 1,725 of them grey `product` boxes
  that represent unlabeled or un-identifiable faces (labelers intentionally
  left them grey). At 0.0625, nearly all 2,457 boxes match *something* in the
  gallery. The denominator explodes (pred canned: 406+887=1,293 vs GT 84;
  pred glass: 29+973=1,002 vs GT 141), and ours' share collapses because
  every grey box that lands nearest a competitor gallery image inflates the
  targeted count. The ours count itself is also wrong (406 canned pred vs 58
  GT): DINOv2 is matching many grey boxes to our own packshots, not rivals.
  **Fix path:** the threshold must be tuned against the *full* box set (named
  + grey), not just the pre-filtered 245. That means adding a "no-match"
  ground truth for grey boxes in the tuning signal (a box the labeler left
  grey is a correct `should_not_match=True` signal, the same as
  `COMPETITOR_glass` today). `shelf-match tune --include-product-boxes` is
  the right shape. Alternatively (cheaper): run the existing tune with the
  gold export's 1,725 grey boxes added to the `should_not_match` pool —
  no labeling work, just a code change in `cli.py tune`. After re-tuning, the
  threshold will be much higher (expect ~0.7-0.8 range) and most grey boxes
  will correctly fall through to `COMPETITOR_<pack>`.
  - [ ] Open: add `--include-product-boxes` to `shelf-match tune`; re-tune on
    gold; re-run `shelf-eval --predict`. This is the real T5 deliverable.
